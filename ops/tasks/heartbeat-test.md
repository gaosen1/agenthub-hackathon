# 心跳测试任务（heartbeat-test）

目的：作为定时巡检机制的测试任务，持续运行约 20 分钟。

执行规则：
1. 本任务共 10 轮，严格按轮次顺序执行，一次只执行一轮，禁止在一轮中合并执行多轮。
2. 每一轮先用 Bash 执行一条命令（把 N 替换为当前轮次）：
   `echo "$(date '+%Y-%m-%d %H:%M:%S') round N/10" >> ops/heartbeat/beat.log`
3. 然后执行 `sleep 120` 等待 2 分钟，再进入下一轮。如果 sleep 被中断，重试即可。
4. 每完成一轮，把下方进度清单中对应项从 `[ ]` 改为 `[x]`，写回本文件。
5. 若本会话是从中断中恢复的：先读取下方进度清单，跳过所有已打勾的轮次，从第一个未完成的轮次继续。
6. 全部 10 轮完成后，追加一行：
   `echo "ALL DONE $(date '+%Y-%m-%d %H:%M:%S')" >> ops/heartbeat/beat.log`
