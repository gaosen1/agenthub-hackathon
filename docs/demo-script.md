# AgentHub 录屏演示拍摄脚本

> 目标时长 3'30" 左右（可剪到 90s 短片版）。核心叙事：**本地会话一推上云 → agent 无人值守干活 → 钉钉交付 → 拉回本地无缝续写**。

## 一、产品一句话（开场定调）

AgentHub 是本地 Coding Agent 会话的**云端接力平台**：把本地改到一半的上下文一条命令移交云端沙箱，agent 夜间无人值守执行，钉钉群实时交付，成果拉回本地 git 合并、会话续聊。

要传递的三个记忆点：
1. **一条命令接力**：`ah push --task --bot`，本地 repo + session 全量上云
2. **全程可见可干预**：Web 控制台流式看 agent 干活，钉钉群追问即续跑
3. **成果无损回流**：`ah pull` git 合并 + 会话时间线合并，本地接着聊

## 二、录制前准备清单（开拍前逐项打勾）

### 环境
- [ ] hub 已启动且**录制期间不碰代码**（tsx watch 重启会造成接口空窗）
- [ ] Web 端清掉历史 handoff（列表干净，只留演示用的 1 个任务）
- [ ] Aone 远端无残留沙箱（`listSandboxInfos` 应为 0，或提前预热一个）
- [ ] 沙箱镜像为最新版（含 code-server、无人值守约束）
- [ ] 钉钉机器人 IP 白名单、凭证有效；测试群干净、无关群免打扰

### 演示任务选择（关键）
- [ ] 选 **1~3 分钟能跑完、diff 可视化**的小任务，例如：
  - 「给 README 顶部加一个快速链接区，指向 功能特性 / 使用方法 / 常见问题」
  - 「给 X 模块补一个 utils 函数 + 单元测试」
- [ ] 指令明确无歧义（避免模型反问；无人值守约束虽已兜底，但任务本身要干净）
- [ ] **正式录制前完整预跑一遍**，确认时长、产出、无报错

### 画面
- [ ] 分辨率 1080p+，OBS 双轨（屏幕 + 麦克风）
- [ ] 终端换深色主题 + 等宽字体，字号 ≥14px，与 Web 的终端工业风呼应
- [ ] 布局：终端与浏览器各占半屏（Act 1/4 用终端全屏，Act 2/3 切浏览器/钉钉）
- [ ] 关闭所有通知弹窗（系统勿扰模式）

### 兜底策略
- [ ] 每个实拍环节**先完整录一遍备份**；正式剪辑时逐段取成功版本
- [ ] 沙箱冷启动约 30~60s：要么提前预热，要么剪辑加速 + 字幕「沙箱按需唤醒中」

## 三、分镜脚本

### Act 0 · 开场钩子（0:00–0:12，12s）
| 镜头 | 画面 | 旁白/字幕 |
|---|---|---|
| 1 | 黑底字幕卡 | 「本地 agent 跑到一半，电脑不能关、网不能断、人不能走？」 |
| 2 | 终端 + Web 控制台并置定格 | 「AgentHub：把会话推上云，让它自己干完，钉钉叫你验收。」 |

### Act 1 · 一条命令接力（0:12–0:45，33s）
| 镜头 | 画面 | 旁白/字幕 |
|---|---|---|
| 3 | 本地 repo，`git status` 扫一眼工作区 | 「这是一个改到一半的本地仓库。」 |
| 4 | 敲入 `ah push --task "给 README 顶部加快速链接区…" --bot` | 「一条命令：工作区快照 + 会话上下文打包上云，交给常驻 bot。」 |
| 5 | 特写 push 输出（打包 → 上传 → handoff id） | 字幕：`handoff: hf-xxxxxx 已创建` |

### Act 2 · 云端执行全程可见（0:45–1:50，65s）
| 镜头 | 画面 | 旁白/字幕 |
|---|---|---|
| 6 | Web `/tasks` 列表，新任务 queued → running | 「任务进入队列，沙箱按需唤醒。」 |
| 7 | 详情页 stepper：queued → provisioning → running 推进 | 「五段式生命周期，每一步都有时间戳。」 |
| 8 | **右侧 Web Shell 流式输出**（核心镜头，留 15s+） | 「这是云端 qwen-code 的原生界面——agent 正在读代码、改文件，全程流式可见。」 |
| 9 | 日志卡 + 产物卡滚动 | 「工具调用、git 操作逐条留痕。」 |
| 10 | （可选）切 IDE 面板 code-server | 「想看完整代码？云端 IDE 直接打开。」 |

> 剪辑要点：agent 思考的静默段加速 4~8x，保留「改文件 / commit」两个高光帧。

### Act 3 · 钉钉交付与追问（1:50–2:35，45s）
| 镜头 | 画面 | 旁白/字幕 |
|---|---|---|
| 11 | 钉钉群弹出「✅ 云端任务完成」卡片（含摘要 + commits 数） | 「干完了，钉钉主动交付：干了什么、几个 commit，一目了然。」 |
| 12 | 在群里发追问：「链接区再加一个 常见问题 锚点」 | 「不满意？群里直接说。」 |
| 13 | bot 回复新改动摘要 | 「常驻会话接着跑——不用重新 push，上下文全在。」 |

> 消息有秒级延迟：剪辑直接切，或字幕「…几秒后」。

### Act 4 · 拉回本地无缝续写（2:35–3:15，40s）
| 镜头 | 画面 | 旁白/字幕 |
|---|---|---|
| 14 | 终端 `ah pull`，输出合并过程 | 「一条命令拉回：git 合并 + 会话时间线合并，幂等可重放。」 |
| 15 | `git log` 特写云端 commit 落地 | 「云端的 commit 原样落在本地。」 |
| 16 | （可选）本地 qwen-code 打开同一 session 续聊一句 | 「连对话都能接着聊——这才是真正的会话接力。」 |

### Act 5 · 收尾快闪（3:15–3:40，25s）
| 镜头 | 画面 | 旁白/字幕 |
|---|---|---|
| 17 | Sandbox 面板快切（实例生命周期、活跃度驱动回收） | 「沙箱生命周期活跃度驱动：干着活永不掐断，空闲才回收。」 |
| 18 | OSS 面板快切（输入/返回包可追溯） | 「每个交接的包都有据可查。」 |
| 19 | 结尾字幕卡 | 「AgentHub · 本地 Coding Agent 的云端接力」+ 仓库地址 |

## 四、防翻车备忘（血泪教训版）

1. **录制期间绝对不改 hub-server 代码**——watch 重启会让前端轮询成片报错
2. push 后沙箱冷启动有窗口期，**等 status 变 running 再切 Web 画面**
3. 演示任务避免「帮我选 A 还是 B」类模糊指令（无人值守约束会强制模型自主决策，但可能产生你不想要的方向）
4. 钉钉消息到达有延迟，旁白节奏预留气口
5. 24h 长任务能力是**口播点**不是实拍点（「夜间无人值守任务活跃即续命，永不撞墙钟」一句话带过）
6. 若现场某环节失败：切备份素材，不要现场调试（调试画面一帧都不要留）

## 五、90 秒短片版裁剪

保留镜头：4（push 命令）→ 8（流式干活）→ 11（钉钉交付）→ 14/15（pull + git log）→ 19（结尾卡）。
